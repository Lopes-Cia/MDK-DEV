# IA/DESENHOS

## Objetivo
- Guardar propostas e desenhos de organização/arquitetura do repo.

## Como usar
- Cada proposta deve virar um arquivo `.md` com data/título ou nome descritivo.
- Se uma proposta virar padrão, mova/duplique para o local definitivo (ex.: IA/DECISOES) e atualize referências.
