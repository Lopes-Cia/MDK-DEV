# MICROSERVICE-DEVDASH


## OBJETIVO
Criar um dashboard interno de desenvolvimento (DEVDASH) em Next.js dentro de `WWW/MICROSERVICE/DEVDASH`, focado em acelerar desenvolvimento e testes (ambiente dev), com ferramentas para simular dados/serviços e validar o front.

## RECURSOS
- MOCK-SERVER (MOCK-END) para servir dados e simular respostas para desenvolvimento/testes.
- Bricks/Builder: editor de bricks com Puck, operado via dashboard em `/{tenant}/dashboard/builder` (não no front público).
- TESTEinAUTO: novo microserviço para testar o front automaticamente.
- Scrapper: coletor para gerar/atualizar dados de teste.
- Seeding: geração de dados iniciais (catálogo/tema/copy etc.) para suportar dev/testes.
