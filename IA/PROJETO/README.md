## IA/PROJETO

Esta pasta guarda “fechamentos de versão” do projeto em arquivos Markdown.

## Como funciona

- Quando você pedir para “fechar essa versão do projeto”, eu devo:
  - Criar um arquivo `version_(YYYY-MM-DD).md` com a data atual.
  - Abrir o assunto no chat fazendo perguntas objetivas para você registrar feedback e observações.
  - Preencher o arquivo com base no que você responder (ou deixar o template pronto para você editar).

## Convenção de nome

- `version_(YYYY-MM-DD).md`

## O que registrar em cada versão

- Estado atual (o que está pronto e o que falta)
- Feedback do que funcionou / não funcionou
- Decisões tomadas e por quê (curto e direto)
- Pendências, riscos e bloqueios
- Próximos passos recomendados
