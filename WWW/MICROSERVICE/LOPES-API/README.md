## Como usar

1. Abra o link no navegador e salve o JSON (ou copie a URL).
2. Para visualizar em UI:
   - Swagger Editor: https://editor.swagger.io/ (File > Import URL)
   - Swagger UI local/online (qualquer instância que aceite uma URL de spec)
3. Se a API exigir autenticação, use o fluxo oficial de token do ambiente e envie o header `Authorization` nas requisições.
